# iiot-monitoring-system
Industrial IIoT monitoring system based on ESP32, MQTT and InfluxDB.

## Project Overview

The project was created as part of Industry 4.0 university coursework.

The system enables:
- real-time industrial data monitoring,
- data transmission using MQTT,
- data archiving in InfluxDB,
- visualization of process parameters,
- modular communication between system components.

## Technologies
- ESP32
- MQTT
- InfluxDB
- HMI
- IIoT

## Scope of work
- system integration,
- data flow architecture,
- data conversion and processing,
- monitoring system configuration,
- testing and validation.
